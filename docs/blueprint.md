# **App Name**: KanbanFlow

## Core Features:

- Board Creation: Users can create multiple boards to manage different projects or aspects of their work.
- List Creation: Users can add lists to each board to represent stages in a workflow (e.g., 'To Do,' 'In Progress,' 'Completed').
- Card Creation: Users can create cards within each list to represent individual tasks or items.
- Drag and Drop Functionality: Cards can be dragged and dropped between lists to update their status in the workflow.
- Card Details: Users can open cards to view and edit details like descriptions, due dates, assignees, and attachments.
- User authentication: Allow user authorization with secure credentials
- Data Persistency: Allow users to save boards and card information in a external database.

## Style Guidelines:

- Primary color: Soft blue (#5A8DEE) to evoke calmness and focus.
- Background color: Very light gray (#F7F9FB), almost white, for a clean, uncluttered workspace.
- Accent color: Muted green (#66BB6A) to highlight completed tasks and important actions.
- Font: 'Inter' (sans-serif) for a clean, modern, and highly readable interface; suitable for both headings and body text.
- Use simple, minimalist icons from a consistent set (e.g., Material Design Icons) to represent actions and categories.
- Use a clear, card-based layout with consistent spacing and alignment to promote usability and readability.
- Incorporate subtle animations for drag-and-drop interactions and state transitions to provide feedback and enhance the user experience.
